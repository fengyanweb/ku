# Ku v0.0.2 记录

## 目标

Ku v0.0.2 在 v0.0.1 的解释器闭环上继续补齐日常写代码需要的基础语法，同时保持四原则：稳定、低资源、快、语法简单。

## 已完成

- 版本同步到 `0.0.2`，语言版本和解释器版本暂时一一对应。
- CLI 支持 `ku -v`、`ku --version`、`ku version`，输出 `ku 0.0.2`。
- CLI 支持 `ku -h`、`ku -help`、`ku --help`、`ku help` 输出命令帮助。
- CLI 支持直接运行 `.ku` 文件：`ku hello.ku` 等价于 `ku run hello.ku`。
- CLI 对缺少参数、多余参数、未知命令给出更明确的错误和帮助。
- CLI 在读取文件前先检查扩展名，避免把 `ku.exe` 之类的二进制当源码读。
- 变量支持首次赋值声明和自动类型推断：`name = 'Ku'`。
- 数据类型当前收口为 `int`、`float`、`bool`、`str`、`null`。
- 类型默认声明支持 `name:str`、`count:int`、`price:float`、`ok:bool`、`empty:null`。
- 全大写或全大写加下划线的名字按常量处理，例如 `APP_NAME = 'ku'` 后不能再次赋值。
- 字符串支持双引号和单引号。
- `print` 支持反引号模板字符串，例如 ``print(`Hello {name} {1 + 2}`)``。
- 反引号模板插值里允许 `str + int/float` 拼接，其他跨类型运算仍在 check 阶段报错。
- 新增最小字符串基础内置函数：`len(str): int`、`str(value): str`。
- 函数值支持 JS 风格箭头函数：`add = (a, b) => { return a + b }`。
- 函数调用支持变量里的函数值：`print(add(10, 20))`。
- 函数值调用会根据实参类型检查函数体并推导返回类型，避免 typed 变量/函数返回值被 `unknown` 绕过。
- 函数系统收紧：`main` 不能带参数，函数参数名不能重复，箭头函数参数名不能重复。
- typed function 如果声明了返回类型但没有可见 `return`，会在 check 阶段报错。
- 错误提示至少包含文件名、行号、列号和源码行。
- 递归调用深度上限收紧到 64，继续保留执行步数上限，避免无限递归或死循环长期吃资源。
- 新增 `examples/v002_features.ku` 覆盖 v0.0.2 语法组合。
- 新增 CLI 和语言测试，覆盖版本命令、帮助命令、直接运行、非 `.ku` 拒绝、模板字符串、箭头函数、常量重赋值、缺失 return、递归保护、无限 while 保护、函数值类型闭环、五基础类型矩阵、资源限制、`null`。
- 新增 `docs/syntax.md` 固定 0.0.3 语法边界。
- 新增 `types.ku`、`template_string.ku`、`constants.ku`、`builtins.ku`、`control_flow.ku` 示例。

## 当前语义

```ku
fn main() {
    name = 'Ku'          // 首次赋值：声明 + 赋值 + 自动推断为 str
    count:int           // 只声明：默认值为 0
    text:str            // 默认值为 ""
    empty:null          // 默认值为 null
    APP_NAME = 'ku'     // 全大写名字是常量，后续不可改

    add = (a, b) => {
        return a + b
    }

    count = add(10, 20)
    print(len(name))
    print(str(count))
    print(`Hello {name} {count}`)
}
```

## 仍不做

- 顶层脚本式执行，仍然要求从 `fn main()` 进入。
- 数组、map、struct、模块、包管理。
- C 后端和 `ku build`。
- 复杂模板字符串嵌套表达式，当前 `{...}` 里放普通表达式。
- 箭头函数闭包捕获外层变量，当前函数值只支持参数和函数体本身。

## 验证方式

```powershell
cargo test
cargo run -- -v
cargo run -- run examples\v002_features.ku
cargo run -- check examples\v002_features.ku
```

构建 release 版本：

```powershell
cargo build --release
Copy-Item target\release\ku.exe release\ku.exe -Force
```
