# Ku v0.0.3 记录

## 已完成

- 解释器版本同步到 `ku 0.0.3`。
- 支持数组、结构体、enum、对象字面量和跨文件 import 基础能力。
- 支持三种 import：`import name from "./mod"`、`import { A } from "./mod.ku"`、`import "./mod.ku"`。
- 导出规则固定为顶层名字首字母大写对外可见，小写只在当前文件内部使用。
- `if` 和 `while` 条件必须带小括号。
- 支持函数内部声明局部函数，例如 `fn go(name: str) { ... }`。
- `ku check` 覆盖词法、语法、基础语义、函数参数数量、变量未定义、重复声明和核心类型错误。
- 顶层源码和 import 文件读取增加 1MB 上限，避免超大源码在 lex/parse 前吃资源。
- import 启动路径优化：入口文件不再重复 parse，named import 不再按每个名字重复展开模块。

## 当前仍不支持

- 闭包捕获外层局部变量。
- `switch` / `match` 和 enum payload 构造。
- 命名空间导入里的结构体/enum 路径访问，例如 `math.User`。
- 数组元素赋值、结构体字段赋值。
- 包管理、异步、错误处理语法和 native 后端。
