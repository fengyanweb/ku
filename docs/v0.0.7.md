# Ku v0.0.7 记录

## 已完成

- 解释器版本同步到 `ku 0.0.7`，CLI 版本改为读取 Cargo 包版本。
- `checker` 继续拆分：stdlib 类型签名抽到 `src/stdlib/metadata.rs`，checker 只负责套用签名和生成诊断。
- 新增 `array.try_get(array, index): T!`，越界和负数返回 `Err(str)`。
- 新增 `string.slice(text, start, end): str!`，按字符下标切片，越界返回 `Err(str)`。
- 修复 `?` 在 `if/while/for` 条件和 `fail/panic` 表达式里不能立刻短路的问题。
- 新增 package 草案和本地闭环：`ku.mod`、package name、import root、cache 路径。
- 新增 IR 草案和 `ku ir <file.ku>` 命令。
- 新增 release history 自动化脚本 `scripts/archive-release.ps1`。
- 新增 `tests/language_v007_test.rs` 覆盖 stdlib Result、package、IR、`?` 短路。

## 仍未完成

- 远程包管理还没有做：0.0.7 只固定本地包边界、import root 和 cache 目录。
- async / await 还没有做：需要任务模型、事件循环和阻塞 stdlib 边界。
- native C / LLVM 后端还没有做：0.0.7 先做 IR，不直接跳后端。
- 引用捕获闭包还没有做：会改变 `Env` / `Value` 所有权模型。
- 复杂嵌套模式和 match 穷尽性检查还没有做：需要类型信息和模式矩阵。

## 验证命令

```powershell
cargo fmt
cargo test --test language_v007_test
cargo test
cargo clippy --all-targets -- -D warnings
cargo build --release
.\scripts\archive-release.ps1 -CheckOnly -SkipBuild
```
