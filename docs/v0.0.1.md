# Ku v0.0.1 记录

## 目标

Ku v0.0.1 是第一版可验证语言雏形，目标是把路线图中的最小闭环落到示例和测试入口上：

- `ku run examples/hello.ku` 可以运行基础输出。
- `ku run examples/hello.ku` 可以运行最小示例。
- `ku run examples/main.ku` 可以运行整数计算示例。
- `ku run examples/fib.ku` 可以运行函数递归。
- `ku run examples/loop.ku` 可以运行 `while` 循环并正常终止。
- `ku run examples/function.ku` 可以运行带参数和返回值的函数。
- `ku check examples/error.ku` 可以对明显类型错误给出清楚错误。

## 已补充内容

- `Cargo.toml`：建立 Rust 二进制/库项目，版本号为 `0.0.1`。
- `src/`：补齐 Lexer、Parser、AST、基础检查器、解释器、作用域、运行时值、错误和 CLI。
- `ku run <file.ku>`：解析、检查并执行 `main()`。
- `ku check <file.ku>`：解析并做基础语义检查，能发现明显类型错误、不可变变量赋值、未定义变量/函数、参数数量或类型错误。
- `ku version`：输出 `ku 0.0.1`。
- 资源保护：加入解析深度、检查深度、执行步数、函数调用深度上限，避免坏程序在解析、检查或运行阶段长期占用资源。
- `examples/hello.ku`：字符串变量、字符串拼接和 `print`。
- `examples/hello.ku`：最小入门程序，输出 `Hello Ku`。
- `examples/main.ku`：基础整数变量和表达式示例，输出 `30`。
- `examples/fib.ku`：递归函数、`if`、`return` 和整数计算。
- `examples/loop.ku`：变量首次赋值、`while`、赋值更新和循环终止。
- `examples/function.ku`：函数参数、返回类型和函数调用。
- `examples/error.ku`：用于 `check` 的基础类型错误样例。
- `tests/cli_v001_test.rs`：覆盖 `run`、`check`、错误输出、循环终止风险。
- `tests/language_v001_test.rs`：直接调用库 API，覆盖有效程序、类型错误、不可变赋值、递归深度保护。

## v0.0.1 不做

本版本记录只服务最小可运行闭环，不包含：

- C 后端。
- 泛型、结构体、模块、包管理。
- 异步、网络、多线程运行时。
- 复杂标准库和高级优化。

## 验证方式

后续主程序初始化完成后，可以运行：

```bash
cargo test
```

开发时可以直接用 Cargo 启动解释器：

```bash
cargo run -- run examples\hello.ku
cargo run -- run examples\main.ku
cargo run -- check examples\hello.ku
```

如果需要手动指定二进制位置，可以先设置：

```bash
set KU_BIN=target\debug\ku.exe
cargo test --test cli_v001_test
```

CLI 集成测试找不到 `ku` 二进制时会失败，避免“未真正运行却通过”的假阳性。

构建完成后可以直接运行：

```bash
cargo build
target\debug\ku.exe run examples\hello.ku
target\debug\ku.exe run examples\main.ku
```

本次也额外生成了面向使用者的 release 文件夹：

```bash
release\ku.exe run release\hello.ku
release\ku.exe run release\main.ku
```
