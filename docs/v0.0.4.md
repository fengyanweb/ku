# Ku v0.0.4 记录

## 已完成

- 解释器版本同步到 `ku 0.0.4`。
- 闭包和局部函数支持按值捕获定义点外层局部变量。
- enum payload variant 可以构造，例如 `Expr.Number(1)`。
- 新增 `match` / `switch` 表达式，支持字面量、`_` 和 enum payload 解构模式。
- 支持数组元素赋值，例如 `items[0] = 9`。
- 支持结构体和对象字段赋值，例如 `user.name = "Ku"`。
- namespace import 支持导出的结构体和 enum 路径访问，例如 `lib.User { ... }`、`lib.State.Ready`、`lib.State.Count(1)`。
- `math.User` 这类命名空间类型可以用于函数参数、返回类型和变量类型声明。
- 补充 v0.0.4 测试闭环，覆盖闭包、复合赋值、match、enum payload 和 namespace 类型导入。

## 语义说明

- 闭包捕获是定义时按值快照：闭包创建后，外层变量后续赋值不会改变已经捕获的值。
- 当前复合赋值按值语义修改根变量：`a = b; a.x = 1` 不会影响 `b`。
- 当前复合赋值支持根变量上的一层数组索引或字段赋值；非变量根，例如 `make().x = 1` 会报错。
- `match` 暂不做穷尽性检查；没有匹配分支会在运行时报错。建议显式写 `_` 分支。

## 当前仍不支持

- 包管理。
- async / await。
- try / catch / result 风格错误处理语法。
- native C / LLVM 后端。
- 引用捕获闭包以及闭包修改外层变量。
- 复杂嵌套模式、match guard 和穷尽性检查。
