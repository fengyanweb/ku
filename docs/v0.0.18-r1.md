# Ku 0.0.18 修订版 1

本次按用户决定将调用链、文档、插件及两个确定的缺陷修复纳入 0.0.18 修订版，发布标识为 `v0.0.18-r1`。Cargo、CLI 与 VS Code 扩展版本均保持 `0.0.18`；原 `v0.0.18` 标签与初版下载保留，不覆盖旧资产。是否实际发布以修订版 Release 和对应 CI 为准。

## 本次修复

- 同步 C 后端输出浮点常量时保留浮点标记，修复 `100000000000000000000.0` 被输出为过大 C 整数 token 而无法编译的问题，以及 `1.0 / 2.0` 被当作整数除法得到 `0` 的同根错误；正确结果为 `0.5`。使用初版 native C 构建的相关程序应升级后重新编译。JSON 编解码实现没有变化。
- `time.date(Time)` 的检查结果统一为 `Date!`，与运行时以及带时区的重载一致，调用时使用 `?` 或现有 Result 处理方式。零参数的 `time.date()` 仍直接返回 Date。
- VS Code 插件从包元数据读取自身版本，修正原 0.0.18 插件内部误报 0.0.17，以及标准库补全和时间接口提示。修正版随本次三平台安装包提供；已有同版本扩展需手动重新安装。
- 官网补齐中英文标准库、HTTP、工具与示例，增加 0.0.17 固定文档及更早开发记录入口。

## 调用链修复

- 解释器实例方法分派复用已经求值的接收者；普通函数字段、只读方法同名字段和 HTTP 方法同名字段不再重复执行接收者。只读探测回退先取得所选字段函数、恢复调用者借用，再执行参数，不复制整个结构体。
- `map` 仅对实际数组进入数组逻辑；结构体/静态对象的同名函数字段仍按普通函数调用。`as_int/as_str` 保持既有 KuValue 转换优先级，类型检查明确拒绝其他类型上的同名直接调用；同名字段函数需先绑定变量再调用。普通 JSON 同名数据字段和含函数字段动态对象的转换规则不变。`clone` 保持原有内建优先级。
- IR 按已经求值的接收者类型分派已有方法，接通数组字面量、函数返回数组、字符数组、map、索引和显式 `?` 后的调用链。间接函数调用先选定函数，再从左至右求值参数，不重新执行接收者。
- 普通本地函数值绑定优先于同名顶层函数，不再因调用快速路径错误选中被遮蔽的顶层函数；调用时注入的递归自名称沿用既有全局名称优先级。
- Result 仍需显式处理；接收者或参数通过 `?` 退出后，不执行后续参数及函数体。沿用既有调用清理、只读规则和有副作用参数的绑定快照；临时调用结果不为链式支持新增整值复制。

本次没有新增 struct 方法声明、builder、管道或隐式错误传播。C 后端未实现的结构体函数字段、动态对象函数字段、array.first/last、string.trim/lower/upper 等仍不承诺支持；本次不把它们扩成新 API。native async 与 LLVM 的既有子集不据此扩大。通用值复制/释放及 AST 后续分析保持暂停。

## 本机验证

macOS arm64、Rust 1.89.0：格式、workspace/all-targets 检查、严格 Clippy 和构建通过；112 项既有相关回归通过。16 种普通、只读和 HTTP 同名函数字段在解释器和默认 runner 中均只求值一次；`as_int/as_str` 冲突调用明确拒绝，字段绑定调用及 KuValue 错误转换另行验证；8 类已实现数组链及函数工厂/索引函数调用顺序在解释器、默认 runner、C 三条路径一致。显式错误退出和 JSON 转换冲突已定向验证。

复用既有 native 分配计数钩子，100 轮嵌套字符串/数组调用链共 2600 次分配，逐轮结束均为 0 活跃分配、0 活跃字节，计费峰值 451 字节；该结果仅覆盖本样例，不代表整个进程无分配。一次性源码、探针和产物验证后删除，既有测试源码保留。其他平台结果以本次提交的 CI 为准。

## 下载与既有边界

从 [v0.0.18-r1 Release](https://github.com/fengyanweb/ku/releases/tag/v0.0.18-r1) 下载目标平台归档、并列 manifest 和 `SHA256SUMS`。文件名仍使用 `ku-v0.0.18-<target>.tar.gz`；通过 Release 标签及 manifest、`RELEASE.json` 中的提交号识别本次修订。包内包含 `ku-language-0.0.18.vsix`。从同版本旧插件升级时，在 VS Code 使用“从 VSIX 安装”，或执行 `code --install-extension ./ku-language-0.0.18.vsix --force`。

Ku 仍为实验预发行版。历史 HTTP 504 出现过，短测未复现，根因未确认，正式 30 分钟验收尚未通过。JSON 保持旧默认；通用值复制/释放与 AST 后续保持暂停。完整 M:N、通用网络调度及数据库完整平台矩阵没有在本次补齐。supervise 的平台条件与内存限制边界沿用 [0.0.18 说明](v0.0.18.md#支持平台与内存限制)。
