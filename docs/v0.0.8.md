# Ku 0.0.8

0.0.8 继续补 native 后端和闭包语义的前置条件，不直接跳 C / LLVM。

## 已完成

- 闭包捕获从 Env 快照推进为共享绑定引用捕获。
- 闭包读取外层变量时能看到最新值。
- 闭包内修改外层可变变量会写回外层。
- 修复本地函数递归的 checker/runtime 闭环。
- IR 从字符串摘要推进到 typed CFG 草案。
- IR 增加 `IrExpr`、`IrLValue`、`IrTerminator`、`FunctionId`、`BlockId`。
- `if` / `while` 降成基础 block 和 branch/jump terminator。
- 首次赋值降成 typed `let`，再次赋值降成 `store`。

## 仍未完成

- 闭包自由变量精确捕获还未做，目前仍会共享整个 Env 作用域。
- 闭包循环引用治理还未做。
- `for`、`try/catch/finally`、复杂 `match` 的完整 IR lowering 还未做。
- native C / LLVM 后端还未做。
- async / await、远程包管理、lockfile 还未做。
