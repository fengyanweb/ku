Это руководство знакомит с основным синтаксисом. Нормативными остаются [спецификация синтаксиса](https://github.com/fengyanweb/ku/blob/v0.0.18-r1/docs/syntax.md) и [спецификация семантики](https://github.com/fengyanweb/ku/blob/v0.0.18-r1/docs/semantics.md) репозитория. Это учебные фрагменты; различия описаны в [поддержке бэкендов](/ru/v0.0.18/docs/support/).

## Переменные и типы

```ku
name = "Ku"
count:int = 3
ready:bool = true
values:[int] = [1, 2, 3]
count += 1
```

Первое присваивание объявляет переменную. Примитивные типы: `int`, `float`, `bool`, `str` и `null`. Целые числа — знаковые 64-битные; числа с плавающей точкой используют binary64. Целые числа не преобразуются в условия по неявной истинности.

## Функции и управление потоком

Этот полный базовый пример взят из `examples/function.ku`:

```ku
fn add(a: int, b: int): int {
    return a + b
}

fn main() {
    println(add(10, 20))
}
```

Ожидаемый вывод: `30`. Этот фрагмент управления потоком можно поместить внутрь `main`:

```ku
total = 0
for i in 5 {
    total += i
}
if (total == 10) {
    println("sum ok")
}
```

`for i in 5` перебирает значения от `0` до `4`. `if` и `while` требуют условия типа `bool`. Несколько инструкций заключаются в фигурные скобки. Для выражений ветвления используется `match`; `switch` отсутствует.

## Владение и заимствование только для чтения

Owned-значения по умолчанию перемещаются и детерминированно освобождаются при выходе из области владельца. Независимая копия требует `.clone()`. Ku не вводит глобальный трассирующий GC; общие внутренние структуры, например окружения замыканий, могут использовать подсчёт ссылок и иметь расходы времени выполнения. Синхронное заимствование только для чтения объявляется как `&name: T`. Обычный Owned-параметр может переместить значение, даже если только читает его. Вызов остаётся `length(value)`, без `&value`; заимствование async не поддерживается.

`int`, `float`, `bool` и `null` — значения Copy. Строки, массивы, объекты, структуры, перечисления, Results и значения функций — Owned. Присваивание и обычные аргументы по умолчанию перемещают значения с владением. Для независимого значения используйте `.clone()`. Tasks клонировать нельзя.

```ku
original = "Ku"
copy = original.clone()
println(original)
println(copy)
```

Синхронная функция может объявить заимствованный параметр только для чтения:

```ku
fn length(&text: str): int {
    return text.len()
}
```

Вызывайте её как `length(value)`, без `&` у аргумента. Заимствованные данные нельзя изменять, перемещать из них значения или выводить за пределы вызова. Такие сочетания, как заимствованные параметры async, пока не поддерживаются. Заимствование только для чтения не гарантирует произвольной чистоты функции.

## Структуры, объекты и модули

```ku
struct User {
    name: str
    age: int
}

user = User { name: "Ku", age: 1 }
println(user.name)
```

Динамические объекты используют `{ name: "Ku" }`. Обычное обращение к отсутствующему индексу объекта завершается ошибкой. `value["name"]?` выполняет поиск через Result и при успехе возвращает `KuValue`. Для конкретного типа используйте `.as_str()?` или `.as_int()?`. Отсутствующий ключ не превращается незаметно в `null`.

Импорты стандартной библиотеки используют пути с точками, например `import json from "std.json"`. Локальные модули могут использовать `import math from "./math"`. Имена пользовательских экспортов верхнего уровня начинаются с заглавной ASCII-буквы; имена со строчной буквы остаются закрытыми внутри файла.

## Обрабатываемые ошибки

Тип результата `T!` возвращает T или Error. `?` передаёт обрабатываемую ошибку вызывающему коду; `fail` создаёт её:

```ku
fn read_name(): str! {
    fail "name missing"
}

fn main() {
    try {
        println(read_name()?)
    } catch (error) {
        println(error.message)
    }
}
```

Error содержит поля `domain`, `code` и `message`. Обычный `catch` не перехватывает `panic`, отмену Task или тайм-аут. Очистка при отмене в finally использует общий бюджет абсолютного срока; завершение произвольной пользовательской очистки не гарантируется.

## Границы конкурентного выполнения

Код приложения получает одноразовый дескриптор Task вызовом `async fn`, затем использует `await`. Прикладных API с именами `task.spawn`, `Task.new` или `thread.spawn` нет. Покрытие интерпретатора и нативного подмножества Task различается. Работа примера в одном бэкенде не доказывает полную поддержку в другом. См. [поддержку платформ и бэкендов](/ru/v0.0.18/docs/support/).
