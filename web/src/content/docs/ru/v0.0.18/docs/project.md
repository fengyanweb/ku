Ku — язык программирования и набор инструментов: интерпретатор, исполняемый runner по умолчанию и нативная компиляция поддерживаемого подмножества через C.

## Исходный код и лицензирование

Ознакомьтесь с [кодом на GitHub](https://github.com/fengyanweb/ku) и [страницей выпуска](https://github.com/fengyanweb/ku/releases/tag/v0.0.18-r1). Код доступен для публичного просмотра, однако собственный код Ku **не имеет предоставленной лицензии с открытым исходным кодом**. Расширение редактора помечено `UNLICENSED`. Публикация исходников или бинарных файлов не предоставляет такую лицензию автоматически.

Уведомления о сторонних компонентах в архивах выпусков относятся только к соответствующим компонентам. Они не устанавливают разрешений на использование, изменение или распространение самой Ku. Необходимое разрешение должно явно исходить от сопровождающего; сайт не создаёт новых лицензионных обязательств.

## Сообщение о проблеме

Воспроизводимые отчёты отправляйте в [Issues](https://github.com/fengyanweb/ku/issues) репозитория. Укажите:

- Версию Ku, коммит Git для исходников разработки и целевую систему / архитектуру.
- Полную команду, бэкенд и минимальный исходный файл `.ku`.
- Полную диагностику или структурированный Error, ожидаемый и фактический вывод.
- Версии инструментов Rust / C для проблем сборки и наличие локальных импортов.

Не отправляйте токены, пароли, реальные строки подключения или журналы с конфиденциальными бизнес-данными. Отчёт о производительности должен содержать окружение, нагрузку, метод измерения и сырые результаты. Один успешный пример не подтверждает производственную пропускную способность.

## Перед участием

Для участия указывайте минимальное воспроизведение, область изменений и подходящие проверки. Код и документация должны соответствовать одной версии. Условия принятия вклада и права использования, изменения и распространения Ku согласуются с сопровождающим.

Сайт не предоставляет онлайн-выполнение кода Ku.

Продолжите с [начала работы](/ru/v0.0.18/docs/getting-started/), [границ поддержки](/ru/v0.0.18/docs/support/) и [примечаний к выпускам](/ru/v0.0.18/releases/).
