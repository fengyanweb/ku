Сначала [установите Ku](/ru/docs/install/) и убедитесь, что `ku --version` выполняется.

## Первая программа

Создайте `hello.ku` с тем же содержимым, что и `examples/hello.ku` в репозитории:

```ku
fn main() {
    println("Hello Ku")
}
```

`fn main()` — точка входа. `println` выводит строку текста. Ku не использует `let` или `let mut`.

## Проверка и запуск

В каталоге файла выполните:

```sh
ku check hello.ku
ku run hello.ku
```

`check` проверяет лексические, синтаксические и базовые семантические ошибки без запуска программы. Ожидаемый стандартный вывод при запуске:

```text
Hello Ku
```

Если Ku отсутствует в `PATH`, вызовите исполняемый файл по полному пути установки. В Windows он называется `ku.exe`.

## Переменные и функции

Этот фрагмент базового синтаксиса можно поместить внутрь `main`:

```ku
name = "Ku"
count:int = 3
println(name)
println(count)
```

Первое присваивание объявляет переменную. Явный тип задаётся как `name:type = value`. `print` выводит текст без автоматического перевода строки; `println` добавляет его.

## Сборка исполняемого файла

Необходимые инструменты перечислены на странице установки. Для бэкенда по умолчанию:

```sh
ku build hello.ku
```

Бэкенд по умолчанию упаковывает средство запуска интерпретатора. Для нативной компиляции через C требуется отдельный компилятор C:

```sh
ku build --backend c hello.ku
```

По умолчанию результат находится в `.ku/build/<profile>/`; используйте точный путь, указанный CLI. Возможности двух бэкендов различаются. Успешный `ku check` не доказывает, что нативная сборка завершится успешно.

Примечание: `ku build --native hello.ku` **без `-o` выдаёт только исходный код C**, без компоновки. Для первой скомпилированной программы используйте команду `--backend c` выше.

## Создание проекта

Если нужен каталог пакета, воспользуйтесь встроенным шаблоном:

```sh
ku create HelloWorld --template basic
cd HelloWorld
ku check
ku run
```

Точка входа пакета задаётся в `ku.mod`. `ku create --list` выводит доступные шаблоны. Команд `ku test` и `ku fmt` пока нет.

Продолжите с [руководством по языку](/ru/docs/guide/language/), [устранением неполадок](/ru/docs/guide/errors/) и [поддержкой бэкендов](/ru/docs/support/).
