Документация описывает зафиксированный объём экспериментального предварительного выпуска v0.0.18. Фактическая публикация и файлы загрузки указаны в GitHub Releases. Проект называется **Ku programming language / Ku 编程语言**, а CLI — `ku`. Ku — небольшой язык программирования и интерпретатор в разработке. Текущий публичный выпуск — экспериментальная предварительная версия v0.0.18.

## Исходный код и лицензирование

Собственный код Ku в снимках исходников, содержащих файл лицензии, и текущее расширение редактора распространяются по [Apache License 2.0](https://github.com/fengyanweb/ku/blob/main/LICENSE) (`Apache-2.0`); сведения об авторстве приведены в [NOTICE](https://github.com/fengyanweb/ku/blob/main/NOTICE). См. [код на GitHub](https://github.com/fengyanweb/ku) и [страницу выпуска](https://github.com/fengyanweb/ku/releases/tag/v0.0.18-r1). Сторонние компоненты сохраняют собственные лицензии.

Архивы v0.0.18-r1 и более ранних выпусков сохраняют исходные лицензионные материалы, поставляемые с ними; это изменение лицензии исходников не перепаковывает эти архивы. Использование компилятора Ku не требует публикации исходного кода ваших собственных программ. При распространении программ, содержащих код среды выполнения Ku, соблюдайте применимые требования лицензий и указания авторства, включая уведомления о сторонних компонентах.

## Сообщение о проблеме

Воспроизводимые отчёты отправляйте в [Issues](https://github.com/fengyanweb/ku/issues) репозитория. Укажите:

- Версию Ku, коммит Git для исходников разработки и целевую систему / архитектуру.
- Полную команду, бэкенд и минимальный исходный файл `.ku`.
- Полную диагностику или структурированный Error, ожидаемый и фактический вывод.
- Версии инструментов Rust / C для проблем сборки и наличие локальных импортов.

Не отправляйте токены, пароли, реальные строки подключения или журналы с конфиденциальными бизнес-данными. Отчёт о производительности должен содержать окружение, нагрузку, метод измерения и сырые результаты. Один успешный пример не подтверждает производственную пропускную способность.

## Перед участием

Поведение языка определяют [контракт синтаксиса](https://github.com/fengyanweb/ku/blob/v0.0.18/docs/syntax.md) и [контракт семантики](https://github.com/fengyanweb/ku/blob/v0.0.18/docs/semantics.md). Проверяйте CI, реализацию и контракты вместе. Цель рабочего журнала не равна реализованной функции.

Сосредоточьте изменения на задаче и объясните воспроизведение, причину, границы и проверку. Сверяйте содержание сайта с соответствующим кодом. Сохраняйте существующие тесты, изменения рабочего дерева и уникальные доказательства. Условия принятия вклада и лицензирования определяет сопровождающий; сайт не придумывает соглашение об участии.

Это статический сайт. Текст, навигация и код не требуют бизнес-бэкенда. Поиск загружает индекс Pagefind в браузер; сайт не предоставляет удалённое выполнение кода Ku.
