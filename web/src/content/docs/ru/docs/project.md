Ku — язык программирования и набор инструментов: интерпретатор, исполняемый runner по умолчанию и нативная компиляция поддерживаемого подмножества через C.

## Исходный код и лицензирование

Ku и расширение VS Code распространяются по лицензии **Apache-2.0**. См. [исходный код](https://github.com/fengyanweb/ku), [выпуск 0.0.19](https://github.com/fengyanweb/ku/releases/tag/v0.0.19) и [текст лицензии](https://github.com/fengyanweb/ku/blob/v0.0.19/LICENSE).

Для сторонних компонентов действуют их собственные лицензии. Пакеты выпуска содержат соответствующие тексты лицензий и уведомления.

## Сообщение о проблеме

Воспроизводимые отчёты отправляйте в [Issues](https://github.com/fengyanweb/ku/issues) репозитория. Укажите:

Обратная связь по почте: [kagura.gc@qq.com](mailto:kagura.gc@qq.com)

- Версию Ku, коммит Git для исходников разработки и целевую систему / архитектуру.
- Полную команду, бэкенд и минимальный исходный файл `.ku`.
- Полную диагностику или структурированный Error, ожидаемый и фактический вывод.
- Версии инструментов Rust / C для проблем сборки и наличие локальных импортов.

Не отправляйте токены, пароли, реальные строки подключения или журналы с конфиденциальными бизнес-данными. Отчёт о производительности должен содержать окружение, нагрузку, метод измерения и сырые результаты. Один успешный пример не подтверждает производственную пропускную способность.

## Перед участием

Ограничивайте изменения конкретной задачей и прилагайте минимальный пример воспроизведения, область влияния и результаты проверок. Код, документация и примеры должны относиться к одной версии. Сопровождающие проверяют изменения перед слиянием.

Сайт не предоставляет онлайн-выполнение кода Ku.

Продолжите с [начала работы](/ru/docs/getting-started/), [границ поддержки](/ru/docs/support/) и [примечаний к выпускам](/ru/releases/).
