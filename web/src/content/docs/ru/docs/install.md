## 2. Распаковать и запустить

Распакуйте **весь пакет** в пустую папку, например `ku` в домашнем каталоге. Храните все файлы вместе; не переносите отдельно исполняемый файл. Откройте терминал в этой папке.

macOS / Linux:

```sh
./ku --version
```

Windows PowerShell:

```powershell
.\ku.exe --version
```

Должно появиться `ku 0.0.19`. Теперь можно запускать и проверять файлы `.ku`; для этих операций устанавливать Rust не нужно.

<details>
<summary>Необязательно: запуск ku из любой папки</summary>

Если пакет распакован в `~/ku`, добавьте эту строку в файл запуска оболочки, например `~/.zshrc` или `~/.bashrc`:

```sh
export PATH="$HOME/ku:$PATH"
```

В Windows откройте «Изменение переменных среды для учетной записи», измените пользовательскую переменную `Path` и добавьте полный путь к распакованной папке, например `%USERPROFILE%\ku`. Сохраните существующие записи.

Откройте новый терминал и выполните `ku --version`.

</details>

## 3. Установить расширение VS Code

В разделе расширений VS Code выберите **… → Установить из VSIX…**, откройте `ku-language-0.0.19.vsix` из распакованной папки и перезагрузите окно.

Если Ku отсутствует в `PATH`, укажите в `ku.executablePath` полный путь к `ku` (`ku.exe` в Windows).

<details>
<summary>Проверить загрузку</summary>

Сравните SHA-256 пакета с [SHA256SUMS](https://github.com/fengyanweb/ku/releases/download/v0.0.19/SHA256SUMS). На [странице выпуска](https://github.com/fengyanweb/ku/releases/tag/v0.0.19) для каждого пакета также есть `.manifest.json` с контрольными суммами файлов. Дополнительные инструкции находятся в `README-INSTALL.md` внутри пакета.

</details>

<details>
<summary>Компиляция собственных программ Ku</summary>

Для `ku run` и `ku check` достаточно CLI для нужной платформы. Обычная команда `ku build` дополнительно требует Rust **1.89.0** и системный компоновщик. Для `ku build --backend c` нужны компилятор C и компоновщик целевой платформы. Нативным программам для баз данных также нужны соответствующие клиентские библиотеки, которые не входят в пакет.

</details>

<details>
<summary>Удаление</summary>

Сохраните созданные вами исходные файлы и настройки, затем удалите распакованную папку, добавленную запись `PATH` и расширение VS Code.

</details>
