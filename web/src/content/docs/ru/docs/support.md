## Скачать Ku 0.0.19

Ku 0.0.19 — экспериментальная предварительная версия. Доступны пакеты для macOS ARM64 (Apple Silicon), Windows x64 и Linux x64 (GNU).

[Пакеты и инструкция по установке](/ru/docs/install/)

## Способы выполнения

- **`ku run`**: Интерпретатор языка с общим JSON и синхронными обработчиками HTTP; без клиентов баз данных.
- **`ku build`**: Стандартный runner включает входной файл, но локальным импортам по-прежнему нужны исходные файлы. Требуются Rust **1.89.0** и системный компоновщик.
- **`ku build --backend c`**: Поддерживает синхронный JSON, HTTP с `http.json` и нативные клиенты PostgreSQL, Redis и MySQL. Нужны компилятор C, компоновщик и соответствующие клиентские библиотеки для целевой платформы. Операции базы данных не повторяются автоматически.
- **Task**: Нативный путь Task поддерживает типизированное подмножество: запуск/`await`, таймеры, отдельные операции I/O, именованные async-обработчики HTTP и некоторые запросы PG. JSON в этом пути может только кодировать литералы объектов со скалярными значениями; общего декодирования нет. Полное M:N и общая поддержка I/O ещё не завершены.
- **LLVM**: Текстовый backend LLVM остаётся ограниченным прототипом.

## Известные проблемы

Проверки выпуска и пакетов успешно пройдены для всех трёх платформ. Это не означает общей готовности к промышленной эксплуатации.

- **HTTP 504:** наблюдался ранее, но не воспроизвёлся в последней короткой перепроверке; причина не подтверждена.
- **Скачки задержки при отмене:** в последней 30-секундной перепроверке все 60 000 коротких запросов были корректны. p99 составил **1.557 ms**, максимум — **98.809 ms**; часть запросов всё ещё превышала 20 ms.

Формальная 30-минутная проверка стабильности ещё не пройдена. Короткие измерения её не заменяют.
