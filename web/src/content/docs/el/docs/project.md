Η τρέχουσα τεκμηρίωση αφορά το Ku 0.0.19, μια πειραματική προέκδοση με ίδια έκδοση CLI και επέκτασης VS Code. Η διαθεσιμότητα, τα αρχεία και τα αθροίσματα ελέγχου καθορίζονται από το πραγματικό GitHub Release.

**Ku programming language / Ku 编程语言** · CLI: `ku`.

## Πηγή και αδειοδότηση

[GitHub](https://github.com/fengyanweb/ku) · [v0.0.19 Release](https://github.com/fengyanweb/ku/releases/tag/v0.0.19)

Το Ku και η επέκταση VS Code διατίθενται με την Apache License 2.0. Δείτε τα [LICENSE](https://github.com/fengyanweb/ku/blob/main/LICENSE) και [NOTICE](https://github.com/fengyanweb/ku/blob/main/NOTICE). Τα στοιχεία τρίτων διατηρούν τα δικά τους πνευματικά δικαιώματα και τις άδειες χρήσης τους.

## Αναφέρετε πρόβλημα

Χρησιμοποιήστε τα [Issues](https://github.com/fengyanweb/ku/issues) του αποθετηρίου για αναπαραγώγιμες αναφορές. Συμπεριλάβετε:

- Έκδοση Ku, commit Git για πηγές ανάπτυξης και σύστημα / αρχιτεκτονική στόχου.
- Πλήρη εντολή, backend και ελάχιστη πηγή `.ku`.
- Πλήρες διαγνωστικό ή δομημένο Error, αναμενόμενη και πραγματική έξοδο.
- Εκδόσεις εργαλείων Rust / C για προβλήματα κατασκευής και αν εμπλέκονται τοπικές εισαγωγές.

Μην υποβάλλετε token, κωδικούς πρόσβασης, πραγματικές συμβολοσειρές σύνδεσης ή αρχεία καταγραφής με ευαίσθητα επιχειρησιακά δεδομένα. Οι αναφορές απόδοσης πρέπει να περιλαμβάνουν περιβάλλον, φόρτο, μέθοδο μέτρησης και ακατέργαστα αποτελέσματα. Ένα επιτυχημένο δείγμα δεν τεκμηριώνει παραγωγική ρυθμαπόδοση.

## Πριν συνεισφέρετε

Η [σύμβαση σύνταξης](https://github.com/fengyanweb/ku/blob/v0.0.19/docs/syntax.md) και η [σύμβαση σημασιολογίας](https://github.com/fengyanweb/ku/blob/v0.0.19/docs/semantics.md) ορίζουν τη συμπεριφορά της γλώσσας. Εξετάστε CI, υλοποίηση και συμβάσεις μαζί. Ένας στόχος ημερολογίου εργασίας δεν είναι υλοποιημένη δυνατότητα.

Κρατήστε τις αλλαγές εστιασμένες και εξηγήστε αναπαραγωγή, αιτία, εύρος και επαλήθευση. Ελέγξτε το περιεχόμενο του ιστοτόπου μαζί με τη σχετική πηγή. Διατηρήστε υπάρχουσες δοκιμές, αλλαγές δέντρου εργασίας και μοναδικά στοιχεία. Ο συντηρητής καθορίζει αποδοχή συνεισφορών και όρους αδειοδότησης· ο ιστότοπος δεν επινοεί συμφωνία συνεισφοράς.

Ο ιστότοπος είναι στατικός. Το κείμενο, η πλοήγηση και ο κώδικάς του δεν απαιτούν επιχειρησιακό backend. Η αναζήτηση φορτώνει ευρετήριο Pagefind στον φυλλομετρητή· ο ιστότοπος δεν παρέχει απομακρυσμένη εκτέλεση κώδικα Ku.

Συνεχίστε με τα [πρώτα βήματα](/el/docs/getting-started/), τα [όρια υποστήριξης](/el/docs/support/) και τις [σημειώσεις εκδόσεων](/el/releases/).
