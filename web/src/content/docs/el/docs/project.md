Το Ku είναι γλώσσα προγραμματισμού και εργαλειοθήκη: διερμηνευτής, προεπιλεγμένο εκτελέσιμο runner και εγγενής μεταγλώττιση C υποστηριζόμενου υποσυνόλου.

## Πηγή και αδειοδότηση

Το Ku και η επέκτασή του για το VS Code διατίθενται με άδεια **Apache-2.0**. Δείτε τον [πηγαίο κώδικα](https://github.com/fengyanweb/ku), την [έκδοση 0.0.19](https://github.com/fengyanweb/ku/releases/tag/v0.0.19) και το [κείμενο της άδειας](https://github.com/fengyanweb/ku/blob/v0.0.19/LICENSE).

Τα στοιχεία τρίτων διατηρούν τις δικές τους άδειες. Τα πακέτα έκδοσης περιλαμβάνουν τα αντίστοιχα κείμενα αδειών και τις σχετικές ειδοποιήσεις.

## Αναφέρετε πρόβλημα

Χρησιμοποιήστε τα [Issues](https://github.com/fengyanweb/ku/issues) του αποθετηρίου για αναπαραγώγιμες αναφορές. Συμπεριλάβετε:

Σχόλια μέσω email: [kagura.gc@qq.com](mailto:kagura.gc@qq.com)

- Έκδοση Ku, commit Git για πηγές ανάπτυξης και σύστημα / αρχιτεκτονική στόχου.
- Πλήρη εντολή, backend και ελάχιστη πηγή `.ku`.
- Πλήρες διαγνωστικό ή δομημένο Error, αναμενόμενη και πραγματική έξοδο.
- Εκδόσεις εργαλείων Rust / C για προβλήματα κατασκευής και αν εμπλέκονται τοπικές εισαγωγές.

Μην υποβάλλετε token, κωδικούς πρόσβασης, πραγματικές συμβολοσειρές σύνδεσης ή αρχεία καταγραφής με ευαίσθητα επιχειρησιακά δεδομένα. Οι αναφορές απόδοσης πρέπει να περιλαμβάνουν περιβάλλον, φόρτο, μέθοδο μέτρησης και ακατέργαστα αποτελέσματα. Ένα επιτυχημένο δείγμα δεν τεκμηριώνει παραγωγική ρυθμαπόδοση.

## Πριν συνεισφέρετε

Κρατήστε τις αλλαγές εστιασμένες και συμπεριλάβετε ελάχιστο παράδειγμα αναπαραγωγής, εύρος και αποτελέσματα ελέγχων. Κώδικας, τεκμηρίωση και παραδείγματα πρέπει να αφορούν την ίδια έκδοση. Οι συντηρητές ελέγχουν τις συνεισφορές πριν από τη συγχώνευση.

Ο ιστότοπος δεν παρέχει online εκτέλεση κώδικα Ku.

Συνεχίστε με τα [πρώτα βήματα](/el/docs/getting-started/), τα [όρια υποστήριξης](/el/docs/support/) και τις [σημειώσεις εκδόσεων](/el/releases/).
