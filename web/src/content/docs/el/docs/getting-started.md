Η τεκμηρίωση περιγράφει το οριστικοποιημένο εύρος της πειραματικής προέκδοσης v0.0.18. Η πραγματική δημοσίευση και οι λήψεις καταγράφονται στα GitHub Releases. Αυτή η σελίδα χρησιμοποιεί βασική σύνταξη και εντολές CLI που υπάρχουν ήδη στη v0.0.17. Πρώτα [εγκαταστήστε το Ku](/el/docs/install/) και επιβεβαιώστε ότι εκτελείται το `ku --version`.

## Γράψτε το πρώτο σας πρόγραμμα

Δημιουργήστε το `hello.ku` με το ίδιο περιεχόμενο όπως το `examples/hello.ku` του αποθετηρίου:

```ku
fn main() {
    println("Hello Ku")
}
```

Το `fn main()` είναι το σημείο εισόδου. Το `println` γράφει μία γραμμή κειμένου. Το Ku δεν χρησιμοποιεί `let` ή `let mut`.

## Έλεγχος και εκτέλεση

Από τον κατάλογο του αρχείου:

```sh
ku check hello.ku
ku run hello.ku
```

Το `check` ελέγχει λεξικά, συντακτικά και βασικά σημασιολογικά σφάλματα χωρίς να εκτελεί το πρόγραμμα. Η αναμενόμενη τυπική έξοδος κατά την εκτέλεση είναι:

```text
Hello Ku
```

Αν το Ku δεν βρίσκεται στο `PATH`, καλέστε το εκτελέσιμο με την πλήρη διαδρομή εγκατάστασης. Το εκτελέσιμο των Windows είναι το `ku.exe`.

## Μεταβλητές και συναρτήσεις

Αυτό το απόσπασμα βασικής σύνταξης μπορεί να τοποθετηθεί μέσα στη `main`:

```ku
name = "Ku"
count:int = 3
println(name)
println(count)
```

Η πρώτη ανάθεση δηλώνει μια μεταβλητή. Ο ρητός τύπος γράφεται ως `name:type = value`. Το `print` γράφει χωρίς αυτόματη αλλαγή γραμμής· το `println` την προσθέτει.

## Δημιουργία εκτελέσιμου

Η σελίδα εγκατάστασης παραθέτει τα απαιτούμενα εργαλεία κατασκευής. Για τον προεπιλεγμένο backend:

```sh
ku build hello.ku
```

Ο προεπιλεγμένος backend συσκευάζει έναν εκκινητή του διερμηνευτή. Η εγγενής μεταγλώττιση μέσω C απαιτεί ξεχωριστό μεταγλωττιστή C:

```sh
ku build --backend c hello.ku
```

Η προεπιλεγμένη έξοδος βρίσκεται στο `.ku/build/<profile>/`· χρησιμοποιήστε την ακριβή διαδρομή που αναφέρει το CLI. Οι δύο backend καλύπτουν διαφορετικές δυνατότητες. Η επιτυχία του `ku check` δεν αποδεικνύει ότι θα επιτύχει η εγγενής κατασκευή.

Σημείωση: το `ku build --native hello.ku` **χωρίς `-o` παράγει μόνο πηγαίο κώδικα C**, χωρίς σύνδεση. Χρησιμοποιήστε την παραπάνω εντολή `--backend c` για το πρώτο μεταγλωττισμένο πρόγραμμά σας.

## Δημιουργία έργου

Χρησιμοποιήστε ενσωματωμένο πρότυπο όταν χρειάζεστε κατάλογο πακέτου:

```sh
ku create HelloWorld --template basic
cd HelloWorld
ku check
ku run
```

Το σημείο εισόδου του πακέτου ρυθμίζεται στο `ku.mod`. Το `ku create --list` παραθέτει τα διαθέσιμα πρότυπα. Προς το παρόν δεν υπάρχουν εντολές `ku test` ή `ku fmt`.

Συνεχίστε με τον [οδηγό γλώσσας](/el/docs/guide/language/), την [αντιμετώπιση προβλημάτων](/el/docs/guide/errors/) και την [υποστήριξη backend](/el/docs/support/). Οι έξοδοι εδώ είναι αναμενόμενα παραδείγματα και δεν αντικαθιστούν την επαλήθευση εγκατάστασης στην πλατφόρμα σας.
