## Λήψη του Ku 0.0.19

Το Ku 0.0.19 είναι πειραματική προέκδοση. Διατίθενται πακέτα για macOS ARM64 (Apple Silicon), Windows x64 και Linux x64 (GNU).

[Πακέτα και οδηγίες εγκατάστασης](/el/docs/install/)

## Τρόποι εκτέλεσης

- **`ku run`**: Διερμηνευτής για τη γλώσσα, γενική επεξεργασία JSON και σύγχρονους χειριστές HTTP· χωρίς πελάτες βάσεων δεδομένων.
- **`ku build`**: Ο προεπιλεγμένος runner ενσωματώνει το αρχείο εισόδου, αλλά τα τοπικά imports χρειάζονται ακόμη τα αρχεία πηγαίου κώδικα. Απαιτεί Rust **1.89.0** και τον συνδέτη του συστήματος.
- **`ku build --backend c`**: Υποστηρίζει σύγχρονο JSON, HTTP με `http.json` και εγγενείς πελάτες PostgreSQL, Redis και MySQL. Χρειάζεται μεταγλωττιστή C, συνδέτη και κατάλληλες βιβλιοθήκες πελάτη για τον στόχο. Οι λειτουργίες βάσης δεδομένων δεν επαναλαμβάνονται αυτόματα.
- **Task**: Η εγγενής διαδρομή Task υποστηρίζει ένα υποσύνολο με δηλωμένους τύπους με εκκίνηση/`await`, χρονόμετρα, επιλεγμένες λειτουργίες I/O, επώνυμους async χειριστές HTTP και συγκεκριμένα ερωτήματα PG. Το JSON μπορεί εκεί μόνο να κωδικοποιεί λεκτικά αντικείμενα με βαθμωτές τιμές· δεν υπάρχει γενική αποκωδικοποίηση. Το πλήρες M:N και η γενική κάλυψη I/O δεν έχουν ολοκληρωθεί.
- **LLVM**: Το backend κειμένου LLVM παραμένει περιορισμένο πρωτότυπο.

## Γνωστά προβλήματα

Οι έλεγχοι έκδοσης και πακέτων πέρασαν και στις τρεις πλατφόρμες. Αυτό δεν αποτελεί γενική έγκριση για παραγωγή.

- **HTTP 504:** έχει εμφανιστεί στο παρελθόν, αλλά δεν αναπαράχθηκε στον τελευταίο σύντομο επανέλεγχο· η αιτία δεν έχει επιβεβαιωθεί.
- **Αιχμές καθυστέρησης κατά την ακύρωση:** στον τελευταίο έλεγχο 30 δευτερολέπτων και τα 60.000 σύντομα αιτήματα ήταν σωστά. Το p99 ήταν **1.557 ms** και το μέγιστο **98.809 ms**· μερικά αιτήματα ξεπέρασαν ακόμη τα 20 ms.

Η επίσημη δοκιμή σταθερότητας 30 λεπτών δεν έχει περάσει. Οι σύντομες μετρήσεις δεν την αντικαθιστούν.
