Ku는 프로그래밍 언어와 도구 체인입니다. 인터프리터, 기본 실행 가능한 runner, 지원 부분집합의 네이티브 C 컴파일을 제공합니다.

## 소스 및 라이선스

[GitHub 소스](https://github.com/fengyanweb/ku)와 [릴리스 페이지](https://github.com/fengyanweb/ku/releases/tag/v0.0.18-r1)를 확인하세요. 소스는 공개적으로 볼 수 있지만 Ku 자체 코드에는 **오픈 소스 라이선스가 부여되지 않았습니다**. 편집기 확장은 `UNLICENSED`로 표시됩니다. 소스나 바이너리를 공개해도 자동으로 오픈 소스 라이선스가 부여되지는 않습니다.

릴리스 압축 파일의 제삼자 고지는 해당 구성 요소에만 적용됩니다. Ku 자체의 사용, 수정, 재배포 권한을 부여하지 않습니다. 필요한 허가는 유지 관리자가 명시적으로 제공해야 합니다. 이 웹사이트는 새로운 라이선스 약속을 만들지 않습니다.

## 문제 보고

재현 가능한 보고는 저장소의 [Issues](https://github.com/fengyanweb/ku/issues)를 이용하세요. 다음을 포함합니다:

- Ku 버전, 개발 소스의 Git 커밋, 대상 시스템 / 아키텍처.
- 전체 명령, 백엔드, 최소 `.ku` 소스.
- 완전한 진단 또는 구조화된 Error, 예상 출력과 실제 출력.
- 빌드 문제라면 Rust / C 도구 모음 버전 및 로컬 가져오기 관련 여부.

토큰, 비밀번호, 실제 연결 문자열, 민감한 업무 데이터가 포함된 로그는 제출하지 마세요. 성능 보고에는 환경, 부하, 측정 방법, 원시 결과를 포함해야 합니다. 한 번 성공한 표본은 프로덕션 처리량을 입증하지 않습니다.

## 기여하기 전에

기여 시 최소 재현, 변경 범위와 관련 테스트를 첨부하세요. 소스와 문서는 같은 버전을 대상으로 해야 합니다. 기여 수용과 Ku의 사용·수정·재배포 권한은 유지관리자와 확인하세요.

이 사이트는 Ku 코드의 온라인 실행을 제공하지 않습니다.

[시작하기](/ko/v0.0.18/docs/getting-started/), [지원 범위](/ko/v0.0.18/docs/support/), [릴리스 노트](/ko/v0.0.18/releases/)로 이어가세요.
