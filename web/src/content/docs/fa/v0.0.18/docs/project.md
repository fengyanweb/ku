Ku زبان برنامه‌نویسی و زنجیره‌ابزار است: مفسر، runner اجرایی پیش‌فرض و کامپایل بومی C برای زیرمجموعهٔ پشتیبانی‌شده.

## کد منبع و مجوز

[کد منبع GitHub](https://github.com/fengyanweb/ku) و [صفحهٔ انتشار](https://github.com/fengyanweb/ku/releases/tag/v0.0.18-r1) را ببینید. کد منبع برای عموم قابل مشاهده است، اما کد خود Ku **مجوز متن‌باز دریافت نکرده است**. افزونهٔ ویرایشگر با `UNLICENSED` مشخص شده است. انتشار کد یا فایل اجرایی، خودکار مجوز متن‌باز اعطا نمی‌کند.

اعلان‌های اشخاص ثالث در بایگانی انتشار فقط مربوط به اجزای خودشان‌اند. آن‌ها اجازهٔ استفاده، تغییر یا بازتوزیع خود Ku را مشخص نمی‌کنند. هر مجوز لازم باید صریحاً از نگهدارنده دریافت شود؛ این وب‌سایت تعهد مجوز جدیدی ایجاد نمی‌کند.

## گزارش مشکل

برای گزارش قابل بازتولید از [Issues](https://github.com/fengyanweb/ku/issues) مخزن استفاده کنید. این موارد را بیاورید:

- نسخهٔ Ku، شناسهٔ Git commit برای کد توسعه و سیستم / معماری مقصد.
- فرمان کامل، مسیر اجرا و کد حداقلی `.ku`.
- پیام تشخیصی کامل یا Error ساختاریافته، خروجی مورد انتظار و خروجی واقعی.
- در مشکل ساخت، نسخهٔ زنجیره‌ابزار Rust / C و وجود واردسازی محلی.

توکن، گذرواژه، رشتهٔ اتصال واقعی یا گزارش دارای دادهٔ حساس تجاری ارسال نکنید. گزارش کارایی باید محیط، بار، روش اندازه‌گیری و نتایج خام را داشته باشد. یک نمونهٔ موفق، توان عملیاتی محیط تولید را اثبات نمی‌کند.

## پیش از مشارکت

برای مشارکت، بازتولید کمینه، محدودهٔ تغییر و آزمون‌های مربوط را ارائه کنید. سورس و مستندات باید یک نسخه را توصیف کنند. پذیرش مشارکت و اجازهٔ استفاده، تغییر و بازتوزیع Ku را با نگهدارنده هماهنگ کنید.

این وب‌سایت اجرای آنلاین کد Ku ارائه نمی‌دهد.

با [شروع کار](/fa/v0.0.18/docs/getting-started/)، [مرزهای پشتیبانی](/fa/v0.0.18/docs/support/) و [یادداشت‌های انتشار](/fa/v0.0.18/releases/) ادامه دهید.
