## دانلود Ku 0.0.19

Ku 0.0.19 یک پیش‌انتشار آزمایشی است. بسته‌های macOS ARM64 (Apple Silicon)، Windows x64 و Linux x64 (GNU) منتشر شده‌اند.

[بسته‌ها و روش نصب](/fa/docs/install/)

## روش‌های اجرا

- **`ku run`**: مفسر زبان با JSON عمومی و پردازشگرهای همگام HTTP؛ کلاینت پایگاه داده ندارد.
- **`ku build`**: اجراکنندهٔ پیش‌فرض فایل ورودی را در خود قرار می‌دهد، ولی importهای محلی همچنان به فایل‌های منبع نیاز دارند. به Rust **1.89.0** و پیونددهندهٔ سیستم نیاز دارد.
- **`ku build --backend c`**: از JSON همگام، HTTP شامل `http.json` و کلاینت‌های بومی PostgreSQL، Redis و MySQL پشتیبانی می‌کند. کامپایلر C، پیونددهنده و کتابخانه‌های کلاینت سازگار با مقصد لازم‌اند. عملیات پایگاه داده خودکار تکرار نمی‌شوند.
- **Task**: مسیر بومی Task یک زیرمجموعهٔ نوع‌دار شامل شروع/`await`، زمان‌سنج، عملیات منتخب I/O، پردازشگرهای نام‌دار async HTTP و برخی پرس‌وجوهای PG را پشتیبانی می‌کند. JSON در این مسیر فقط می‌تواند اشیای literal با مقادیر اسکالر را کدگذاری کند؛ رمزگشایی عمومی ندارد. M:N کامل و پوشش عمومی I/O هنوز تکمیل نشده‌اند.
- **LLVM**: backend متنی LLVM همچنان یک نمونهٔ اولیهٔ محدود است.

## مشکلات شناخته‌شده

بررسی‌های انتشار و بسته‌ها در هر سه پلتفرم موفق بوده‌اند. این نتیجه تأیید عمومی برای استفاده در محیط عملیاتی نیست.

- **HTTP 504:** در گذشته رخ داده، اما در تازه‌ترین بررسی کوتاه بازتولید نشده است؛ علت هنوز تأیید نشده است.
- **جهش تأخیر هنگام لغو:** در تازه‌ترین بررسی ۳۰ ثانیه‌ای، هر ۶۰٬۰۰۰ درخواست کوتاه درست بود. p99 برابر **1.557 ms** و بیشینه **98.809 ms** بود؛ هنوز برخی درخواست‌ها از ۲۰ میلی‌ثانیه عبور کردند.

آزمون رسمی پایداری ۳۰ دقیقه‌ای هنوز قبول نشده است. اندازه‌گیری‌های کوتاه جای آن را نمی‌گیرند.
