Ku زبان برنامه‌نویسی و زنجیره‌ابزار است: مفسر، runner اجرایی پیش‌فرض و کامپایل بومی C برای زیرمجموعهٔ پشتیبانی‌شده.

## کد منبع و مجوز

Ku و افزونهٔ VS Code آن تحت مجوز **Apache-2.0** منتشر می‌شوند. [کد منبع](https://github.com/fengyanweb/ku)، [نسخهٔ 0.0.19](https://github.com/fengyanweb/ku/releases/tag/v0.0.19) و [متن مجوز](https://github.com/fengyanweb/ku/blob/v0.0.19/LICENSE) را ببینید.

اجزای شخص ثالث مجوزهای خود را حفظ می‌کنند. متن مجوزها و اعلان‌های مربوط در بسته‌های انتشار موجود است.

## گزارش مشکل

برای گزارش قابل بازتولید از [Issues](https://github.com/fengyanweb/ku/issues) مخزن استفاده کنید. این موارد را بیاورید:

بازخورد از طریق ایمیل: [kagura.gc@qq.com](mailto:kagura.gc@qq.com)

- نسخهٔ Ku، شناسهٔ Git commit برای کد توسعه و سیستم / معماری مقصد.
- فرمان کامل، مسیر اجرا و کد حداقلی `.ku`.
- پیام تشخیصی کامل یا Error ساختاریافته، خروجی مورد انتظار و خروجی واقعی.
- در مشکل ساخت، نسخهٔ زنجیره‌ابزار Rust / C و وجود واردسازی محلی.

توکن، گذرواژه، رشتهٔ اتصال واقعی یا گزارش دارای دادهٔ حساس تجاری ارسال نکنید. گزارش کارایی باید محیط، بار، روش اندازه‌گیری و نتایج خام را داشته باشد. یک نمونهٔ موفق، توان عملیاتی محیط تولید را اثبات نمی‌کند.

## پیش از مشارکت

تغییرات را متمرکز نگه دارید و نمونهٔ حداقلی بازتولید، دامنهٔ تغییر و نتیجهٔ بررسی‌ها را ارائه کنید. کد، مستندات و مثال‌ها باید مربوط به یک نسخه باشند. نگهدارندگان پیش از ادغام، مشارکت‌ها را بررسی می‌کنند.

این وب‌سایت اجرای آنلاین کد Ku ارائه نمی‌دهد.

با [شروع کار](/fa/docs/getting-started/)، [مرزهای پشتیبانی](/fa/docs/support/) و [یادداشت‌های انتشار](/fa/releases/) ادامه دهید.
