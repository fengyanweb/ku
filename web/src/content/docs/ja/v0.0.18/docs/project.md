Ku はプログラミング言語とツールチェーンです。インタープリター、既定の実行可能 runner、対応する部分集合のネイティブ C コンパイルを提供します。

## ソースとライセンス

[GitHub のソース](https://github.com/fengyanweb/ku)と[リリースページ](https://github.com/fengyanweb/ku/releases/tag/v0.0.18-r1)をご覧ください。ソースは公開閲覧できますが、Ku 自体のコードには**オープンソースライセンスの許諾がありません**。エディター拡張は `UNLICENSED` と表記されています。ソースやバイナリーの公開は、自動的なオープンソースライセンスの許諾にはなりません。

リリースアーカイブの第三者通知は、それぞれのコンポーネントにのみ適用されます。Ku 自体の使用、改変、再配布の許可を示すものではありません。必要な許可は、保守担当者が明示的に与える必要があります。このウェブサイトは新たなライセンス上の約束を作りません。

## 問題を報告する

再現可能な報告には、リポジトリの [Issues](https://github.com/fengyanweb/ku/issues) を使用してください。次を含めます：

- Ku のバージョン、開発ソースの Git コミット、ターゲットシステム／アーキテクチャ。
- 完全なコマンド、バックエンド、最小の `.ku` ソース。
- 完全な診断または構造化 Error、期待した出力、実際の出力。
- ビルド問題では Rust / C ツールチェーンのバージョンと、ローカルインポートの有無。

トークン、パスワード、実際の接続文字列、機密の業務データを含むログは送信しないでください。性能報告には、環境、負荷、測定方法、生の結果を含めます。1 回の成功例では、本番スループットは証明できません。

## 貢献する前に

貢献には最小再現例、変更範囲、関連テストを添えてください。コードと文書は同じ版を対象にし、貢献の受理や Ku の使用・変更・再配布権限は保守担当者に確認してください。

このサイトは Ku コードのオンライン実行を提供していません。
