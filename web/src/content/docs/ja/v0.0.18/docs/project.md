本書は実験的プレリリース v0.0.18 の確定した範囲を説明します。実際の公開状況とダウンロードは GitHub Releases を確認してください。プロジェクト名は **Ku programming language / Ku 编程语言**、CLI 名は `ku` です。Ku は開発中の小さなプログラミング言語とインタープリターです。現在の公開リリースは v0.0.18 実験的プレリリースです。

## ソースとライセンス

[GitHub のソース](https://github.com/fengyanweb/ku)と[リリースページ](https://github.com/fengyanweb/ku/releases/tag/v0.0.18)をご覧ください。ソースは公開閲覧できますが、Ku 自体のコードには**オープンソースライセンスの許諾がありません**。エディター拡張は `UNLICENSED` と表記されています。ソースやバイナリーの公開は、自動的なオープンソースライセンスの許諾にはなりません。

リリースアーカイブの第三者通知は、それぞれのコンポーネントにのみ適用されます。Ku 自体の使用、改変、再配布の許可を示すものではありません。必要な許可は、保守担当者が明示的に与える必要があります。このウェブサイトは新たなライセンス上の約束を作りません。

## 問題を報告する

再現可能な報告には、リポジトリの [Issues](https://github.com/fengyanweb/ku/issues) を使用してください。次を含めます：

* Ku のバージョン、開発ソースの Git コミット、ターゲットシステム／アーキテクチャ。
* 完全なコマンド、バックエンド、最小の `.ku` ソース。
* 完全な診断または構造化 Error、期待した出力、実際の出力。
* ビルド問題では Rust / C ツールチェーンのバージョンと、ローカルインポートの有無。

トークン、パスワード、実際の接続文字列、機密の業務データを含むログは送信しないでください。性能報告には、環境、負荷、測定方法、生の結果を含めます。1 回の成功例では、本番スループットは証明できません。

## 貢献する前に

言語の挙動は[構文仕様](https://github.com/fengyanweb/ku/blob/v0.0.18/docs/syntax.md)と[意味仕様](https://github.com/fengyanweb/ku/blob/v0.0.18/docs/semantics.md)で定義されます。CI、実装、仕様を併せて確認してください。作業ログの目標は、実装済み機能ではありません。

変更は限定し、再現方法、原因、範囲、検証を説明してください。ウェブサイトの内容は、対応するソースと併せてレビューします。既存テスト、作業ツリーの変更、固有の証拠を保全してください。貢献の受け入れとライセンスの取り決めは保守担当者が決定します。このウェブサイトは貢献契約を新設しません。

このウェブサイトは静的です。本文、ナビゲーション、コードに業務バックエンドは不要です。検索はブラウザーに Pagefind インデックスを読み込みます。サイトは Ku コードのリモート実行を提供しません。
