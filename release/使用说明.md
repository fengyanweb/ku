# Ku 运行方式

这个文件夹是给普通使用者看的，不需要关心 Rust 源码。

当前版本：`ku 0.0.15`

如果需要重新打包解释器和 VS Code 插件，在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package-release.ps1
```

## 直接运行

```powershell
.\ku.exe run hello.ku
.\ku.exe run main.ku
```

也可以省略 `run`：

```powershell
.\ku.exe hello.ku
```

如果当前目录或 Path 里能找到 `ku.exe`，Windows 会自动把 `ku` 解析成 `ku.exe`。

在 CMD 里，当前目录下可以直接写：

```powershell
ku run hello.ku
ku hello.ku
```

在 PowerShell 里，当前目录默认不直接执行程序名，需要写：

```powershell
.\ku.exe run hello.ku
.\ku.exe hello.ku
```

或者把这个 `release` 文件夹加入 Windows Path，之后 PowerShell 里也可以直接写：

```powershell
ku run hello.ku
ku hello.ku
```

## 运行其他 .ku 文件

```powershell
.\ku.exe run 路径\你的文件.ku
```

例如：

```powershell
.\ku.exe run ..\examples\fib.ku
.\ku.exe run ..\examples\imports.ku
.\ku.exe run ..\examples\object.ku
.\ku.exe run ..\examples\v002_features.ku
```

## 检查代码

```powershell
.\ku.exe check hello.ku
```

## HTTP 标准库

HTTP 是独立标准库模块，需要显式导入：

```ku
import "std.http"

fn main(): null! {
    res = http.get("https://example.com")?
    println(res.status)
    return ok(null)
}
```

HTTP client 默认有超时和 body 大小限制。网络、URL、协议或 body 限制错误会返回结构化 `Err({ domain, code, message })`，不会无限重试。

## 输出 IR 草案

```powershell
.\ku.exe ir main.ku
```

## 构建可执行文件

```powershell
.\ku.exe build main.ku
.\ku.exe build --release -o dist\main.exe main.ku
```

当前默认 `ku build` 会生成解释器打包型可执行文件，默认输出到 `.ku\build\<profile>\<name>.exe`。它需要本机能调用 `rustc`，并且这个 release 文件夹里保留 `libku.rlib`；在源码仓库内运行时会自动回退使用相邻的 `target\release\deps` 依赖目录。`ku build --native main.ku` 仍是 prototype C 源码输出；完整 native binary build 还在继续补 native ABI。

## 当前模块导入写法

Ku 按首字母大小写决定包外可见性：顶层名字首字母大写代表可导出，首字母小写代表当前文件私有。

```ku
import math from "./math"
import { Add } from "./math.ku"
import "./math.ku"
```

不要写 `import from "./math.ku"`。

`if` 和 `while` 条件必须写小括号：

```ku
if (ok) {
    print("yes")
}

while (i < 5) {
    i = i + 1
}
```

## 想在任意目录直接输入 ku

如果 VS Code 终端里直接输入 `ku` 提示找不到命令，通常不是 Ku 解释器代码问题，而是 Windows 当前 `Path` 里没有 `ku.exe` 所在目录。

可以先用完整路径验证解释器本身：

```powershell
.\ku.exe -h
.\ku.exe run ..\examples\hello.ku
```

想在任意目录直接输入 `ku`，把这个 `release` 文件夹加入 Windows 的 `Path` 环境变量。之后重启 VS Code 终端，就可以像 `node`、`go` 一样运行：

```powershell
ku run main.ku
ku -h
```

以后你改了 Rust 源码，想生成新的 `ku.exe`，就在项目根目录运行：

```powershell
cd E:\study\ku
cargo build --release
.\scripts\archive-release.ps1
```
